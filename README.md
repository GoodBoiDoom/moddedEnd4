# moddedEnd4

My personal Linux desktop configs — an **end4 (illogical-impulse) + Hyprland** rice
plus the terminals, apps and theming around it.

This repo mirrors the relevant parts of `~/.config` at the repo root. Home-level
dotfiles (things that live directly in `~`) are under `home/`.

## Contents

### Shell & window manager
| Path | What it is |
| --- | --- |
| `quickshell/ii/` | Quickshell shell (end4 / illogical-impulse QML source, scripts, assets) |
| `hypr/` | Hyprland config (`hyprland.lua` + Lua modules), Hyprlock, Hypridle, scripts |
| `illogical-impulse/config.json` | Saved shell settings (bar/widget layout, AI + other prefs) |

### Terminals & shell
| Path | What it is |
| --- | --- |
| `kitty/` | Kitty terminal (`kitty.conf`, search/scroll kittens) |
| `fish/` | Fish shell (config, functions, completions, conf.d) |
| `starship.toml` | Starship prompt |
| `zshrc.d/` | Zsh drop-in snippets |
| `home/.zshrc`, `home/.bashrc`, `home/.bash_profile` | Login shell dotfiles |

### Apps
| Path | What it is |
| --- | --- |
| `btop/` | btop++ system monitor |
| `cava/` | CAVA audio visualizer (config, shaders, themes) |
| `mpv/` | mpv media player |
| `fuzzel/`, `wlogout/`, `foot/`, `alacritty/`, `ghostty/` | Launcher, logout, and terminal configs |
| `neofetch/` | Neofetch config |
| `lazyspotify/` | lazyspotify config |
| `spicetify/` | Spicetify (config + CustomApps) |
| `nvim/` | Neovim (LazyVim) |
| `micro/` | Micro editor (settings, colorschemes, syntax) |

### Theming / appearance
| Path | What it is |
| --- | --- |
| `matugen/` | Matugen templates/config |
| `Kvantum/` | Kvantum Qt themes |

### Browser
| Path | What it is |
| --- | --- |
| `zen/chrome/` | Zen browser `chrome/` folder (installed theme CSS). **No profile data.** |

## Restoring

Back up your existing config first. Configs mirror `~/.config`, so:

```bash
# shell + WM + settings
cp -r quickshell/ii ~/.config/quickshell/ii
cp -r hypr          ~/.config/hypr
cp    illogical-impulse/config.json ~/.config/illogical-impulse/config.json

# other app configs (run from the repo root)
for d in kitty fish btop cava mpv fuzzel wlogout foot alacritty ghostty \
         neofetch lazyspotify spicetify nvim micro matugen Kvantum \
         gtk-3.0 gtk-4.0 xsettingsd kde-material-you-colors zshrc.d; do
  cp -r "$d" ~/.config/"$d"
done
cp starship.toml kdeglobals ~/.config/

# Zen theme
cp -r zen/chrome ~/.config/zen/<your-profile>/chrome

# home dotfiles
cp home/.zshrc home/.bashrc home/.bash_profile home/.gtkrc-2.0 ~/
```

## Notes

- Symlinks inside `quickshell/ii/assets/icons/` are relative and preserved as-is.
- No API keys, tokens, passwords or browser profile databases are stored here.
- `kitty.conf` includes a theme generated by Quickshell at
  `~/.local/state/quickshell/user/generated/terminal/kitty-theme.conf` — that file
  is generated at runtime and is not in this repo.
